One razor-sharp line that gets you out of a pointless work meeting:

> I sent my calendar invite in my place. It's more qualified for this meeting than I am.

## How it works

`main.py` (stdlib only) writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), after a `validate()` gate that mirrors the
bounty gate: UTF-8, 1–200 characters, not whitespace-only, a single line.
It then reads the file back and fails loudly if the bytes differ.

Run it with:

```sh
python3 main.py
```
